**File:** [scripts/rules-baseline-evaluator.py](../scripts/rules-baseline-evaluator.py)

**Rules Logic:**
```python
def rules_baseline_decision(listed: float, tfv: float) -> str:
    if tfv <= 0 or listed <= 0:
        return "NEUTRAL"  # Missing data

    discount_pct = ((tfv - listed) / tfv) * 100

    if discount_pct >= 10.0:  # listed ≤ TFV * 0.90
        return "BUY"
    elif discount_pct <= -10.0:  # listed ≥ TFV * 1.10
        return "PASS"
    else:
        return "HOLD"
```

**Test Suite:**
- 5 BUY cases (10%+ discount)
- 5 PASS cases (10%+ premium)
- 3 HOLD cases (within ±10%)
- 2 NEUTRAL cases (missing data)
